# monopoly

A JavaScript/HTML/CSS Monopoly implementation with full game play. Supports two-eight players.

Play original repo online at [http://www.intrepidcoder.com/projects/monopoly/](http://www.intrepidcoder.com/projects/monopoly/).

Includes an experimental capability to play against an AI. A test AI for demonstration purposes is included.

Play with additional takeover (line get rich) mechanic at [https://m-yazidxx.github.io/monopoly-takeover/](https://m-yazidxx.github.io/monopoly-takeover/)
